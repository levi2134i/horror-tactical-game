# Nightfall Protocol

A compact browser game prototype inspired by tactical hero shooters and horror survival games, but built with original names, mechanics, and art direction.

## Features

- Original playable agents: Vesper, Mire, Sable, Rook, Nox
- Original weapon themes: Bone Chime, Lantern Breaker, Grave Echo, Hollow Spine, Ashen Reaper
- Procedural horror map with control points
- Level progression and score system
- Keyboard + mouse controls
- Clean HTML, CSS, and JavaScript implementation

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- WASD: movement
- Mouse: aim
- Left click: fire
- Space: activate ability
- Shift: dodge / sprint
- R: reload

## Mission

Hold the control points in the haunted Ashen District and survive the night while the cursed horde closes in.
